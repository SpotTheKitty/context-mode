# HTTP hook and legacy import recovery

HTTP hook transport errors fail open using the selected adapter's allow encoding and append one JSON line to dataDir/hook-errors.log. Timeout policy comes from the endpoint table's hookTimeoutMs. Successful server decisions are unchanged.

Imports fold Windows UNC and drive spellings, map old T3 worktrees to their project checkout when present, then walk to the nearest existing ancestor. Session metadata, resume and source rows provide workspace identity. Unresolved or ambiguous rows use SHA-256(tenant + ':legacy'), truncated to 16 hex characters. Explicit ownership mappings win. Per-database digest markers preserve idempotence and reject changed sources.

Sources: src/core/contracts/types.ts (AdapterRow), src/adapters/claude-code.ts (encodeClaudeShape), src/core/hooks/fallback.ts (logHookError); https://code.claude.com/docs/en/hooks (exit-zero with empty output continues); https://nodejs.org/api/sqlite.html (DatabaseSync readOnly and transactions).
